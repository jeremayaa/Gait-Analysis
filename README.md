Human Movement Visualization

Welcome!
This repo allows you to visualize human movement using data from IMU sensors placed on the body.
It includes a sample dataset of human gait.

Current Features:
- View human movement from various 2D perspectives (e.g., xy, xz, yz).
- Trace the path of individual sensors.

Coming Soon:
- Adding the AHRS algorithm to compute positions using accelerometer, gyroscope, and magnetometer data.
- Adding the ability to view the movement from all angles.
